# پنل مدیریت AS Industries

مسیر: `/as-admin?lang=fa` یا `/as-admin?lang=en`.

ظاهر پنل بر اساس تصویر مرجع است؛ عکس‌های هدر و پس‌زمینه ارسالی بدون ویرایش در assets ذخیره شده‌اند. لوگو همان wordmark سایت است. پنل برای موبایل و RTL نیز چیدمان دارد.

دسترسی به APIهای مدیریتی فقط برای Administrator یا System User دارای System Manager مجاز است. فرم مشتری، نقش مدیریتی ایجاد نمی‌کند. داده‌ها از همان دیتابیس سایت و با مجوزهای استاندارد Frappe خوانده می‌شوند. CSRF و ورود/خروج استاندارد باقی مانده‌اند.

صفحه کاربران، جست‌وجو و صفحه‌بندی واقعی دارد؛ ویرایش کاربران و تنظیمات از Desk موجود انجام می‌شود. محصولات و موجودی داخل همین پنل قابل ویرایش‌اند. اتصال با حساب مدیر فروشگاه انجام می‌شود و نشست و مجوز آن سایت مستقل است. جزئیات در INVENTORY.fa.md.

در سایت صنایع فعلاً داک‌تایپ‌های تولید موجود نیستند؛ داشبورد برای داده‌های غایب مقدار «—» و حالت خالی نشان می‌دهد. هیچ آمار یا کاربر ساختگی در دیتابیس اضافه نمی‌شود. adapter فقط در صورت وجود و مجوز خواندن، داک‌تایپ‌های AS Manufacturing Request، AS Production Order، AS Machine، AS Material و AS Quality Check را می‌خواند. نمای آماری حداکثر ۱۰۰۰ رکورد جدید را پوشش می‌دهد و محدودیت در UI نمایش داده می‌شود. زمان تحویل و نمودار حجم فقط از فیلد واقعی completed_on/completed_at/completed_date استخراج می‌شوند.

فایل‌ها: admin.py، www/as_admin.py، www/as-admin.html، public/js/admin.js و public/css/admin.css.
