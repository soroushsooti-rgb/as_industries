مدیریت محصولات و گردش موجودی داخل /as-admin#/inventory است. اتصال به نشست واقعی فروشگاه نیاز دارد و رمز نگهداری نمی‌شود؛ نشست سمت سرور به حساب و نشست صنایع متصل و پس از ۳۰ دقیقه بی‌فعالیتی منقضی می‌شود. API فروشگاه مجوزهای استاندارد اسناد را بررسی می‌کند؛ ذخیره محصول، تغییر موجودی، تأیید/لغو/اصلاح سند، گالری، تاریخچه، یادداشت، اشتراک، ارجاع، چاپ، ورود و خروجی CSV از همین پنل انجام می‌شوند. تغییر تعداد همیشه با سند تأییدشده گردش موجودی اعمال می‌شود. CSV حداکثر ۱۰۰ ردیف در هر درخواست دارد و عملیات هر درخواست یک تراکنش است. حذف محصول دارای اسناد وابسته مثل Desk رد می‌شود؛ برای حذف از سایت، انتشار را غیرفعال کنید. تصاویر عمومی JPG/PNG/WebP تا ۵ مگابایت، ۲۰ میلیون پیکسل و اندازه خروجی حداکثر ۲۰۴۸ پذیرفته می‌شوند. آدرس مقصد فقط از تنظیمات سرور گرفته می‌شود و UI کلید API یا SID فروشگاه دریافت نمی‌کند.
